# 📥 Entrada e Saída de Dados - Portugol

Este projeto contém exemplos de **entrada e saída de dados** utilizando o **Portugol Studio**.  

## 🎯 Objetivos
- Aprender a ler informações digitadas pelo usuário  
- Exibir mensagens e resultados na tela  
- Compreender a base da interação entre programa e usuário

✍️ Desenvolvido para praticar os fundamentos de entrada e saída 🚀
