# 📘 Lógica de Programação com Portugol 📘

Este repositório contém arquivos **.por** desenvolvidos no **Portugol Studio**, com o objetivo de **praticar e fortalecer os conceitos de Lógica de Programação**.  

---

## Objetivos
- Exercitar a lógica de programação em uma linguagem estruturada e didática  
- Desenvolver a capacidade de resolver problemas com algoritmos  
- Criar uma base sólida para linguagens de programação como Python, Java, entre outras  

---

## Observações
Este repositório tem fins **educacionais** e serve como base de estudos em algoritmos e lógica de programação.
