# 📊 Vetores e Matrizes - Portugol

Este projeto contém exemplos de uso de **vetores e matrizes** no **Portugol Studio**.  

## 🎯 Objetivos
- Entender como armazenar vários valores em uma única estrutura  
- Manipular listas (vetores) e tabelas (matrizes)  
- Resolver problemas que envolvem coleções de dados
