# 🔁 Estruturas de Repetição - Portugol

Este projeto contém exemplos de **laços de repetição** no **Portugol Studio**.  

## 🎯 Objetivos
- Utilizar laços como **PARA**, **ENQUANTO** e **REPITA**  
- Automatizar execuções repetitivas  
- Reforçar a importância da iteração em algoritmos
