# 🔀 Estruturas de Controle - Portugol

Este projeto contém exemplos de **estruturas de decisão** (condicionais) no **Portugol Studio**.  

## 🎯 Objetivos
- Compreender o uso do **SE**, **SENÃO** e **ESCOLHA**  
- Aplicar condições lógicas em algoritmos  
- Tomar decisões automáticas dentro do programa
